# Свойства AVFX: что известно

Все поля форматов по Dalamud-VFXEditor (`VFXEditor/Formats/AvfxFormat`), с тем, как они реализованы в рантайме и насколько проверены. Подробности и номера записей — в [findings.md](findings.md).

| Метка | Значение |
|---|---|
| ✅ | проверено по игре |
| 🔶 | вывод из данных или одного наблюдения, по игре не опровергнуто |
| 🛠 | реализовано по-своему: как поле действует в игре, не измерено (или измерено частично) — сделано по нашей логике, что оно «по идее» делает (в примечании) |
| ❓ | догадка или неизвестно |
| ⚠️ | вывод сделан на `abi_gshu1c0c` (не канон) — перепроверить |
| ⬜ | не реализовано: в игре влияет или может влиять, превью пока не делает — работа впереди |
| 🚫 | не нужно превью: сознательно не обрабатываем — на картинку не влияет, в спавне игры не проявляется или решено не делать (причина — в примечании) |
| — | проверка не нужна: счётчик (сколько блоков / ключей), задаёт только устройство файла |

Поля без метки: «читается» — значение берётся в код, но по игре не проверялось; «не читается» — рантайм поле не использует, и ещё **не разобрано**, нужно ли оно превью (после разбора — ⬜ или 🚫).

Порядок работы: брать одно-два свойства со статусом ❓/⚠️/🔶, находить эффект, где они заметны, и сверять с записью игры.
